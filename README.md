# Pharmacovigilance Adverse Event System

This project is a web-based application designed to simulate the workflow of pharmacovigilance case processing.
It focuses on handling adverse drug event (ADE) data, similar to how Individual Case Safety Reports (ICSRs) are managed in real-world healthcare and regulatory environments.

Overview

Pharmacovigilance plays a critical role in drug safety by monitoring and evaluating adverse drug reactions.  
This project demonstrates a simplified version of that process, from data entry to structured case handling.

Key Features

- Adverse Event (AE) data capture  
- Structured case handling workflow  
- Basic validation and processing logic  
- Organized data representation for analysis  
- Simulation of real-world pharmacovigilance operations
